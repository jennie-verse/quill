# Quill 사용 안내

화면의 메뉴는 영문입니다. 아래에서는 한국어 설명과 함께 적었습니다.

---

## 1. 홈 화면에 추가하기

1. Safari에서 `https://jennie-verse.github.io/quill/` 를 엽니다.
2. 아래쪽 **공유(Share)** 버튼을 누릅니다.
3. **홈 화면에 추가(Add to Home Screen)** 를 누릅니다.
4. 이름을 확인하고 **추가(Add)** 를 누릅니다.

홈 화면 앱으로 열면 주소창이 사라져 화면이 넓어지고, Safari보다 저장 데이터가 오래 유지됩니다.

> **Safari 탭과 홈 화면 앱은 저장 공간이 분리됩니다.** 두 곳에서 번갈아 쓰면 초안이 서로 보이지 않습니다. 한 곳만 정해서 쓰세요.

---

## 2. 기본 사용

### 파일 열기

**Open** → Files 앱이 열립니다 → 편집할 파일을 고릅니다.

- 텍스트가 아닌 파일을 고르면 `This appears to be a binary file.` 안내가 뜹니다. 그래도 열려면 **Open Anyway**, 취소하려면 **Cancel** 을 누릅니다.
- 저장하지 않은 변경이 있으면 먼저 확인창이 뜹니다. **Discard Changes**(변경 버리기) 또는 **Keep Editing**(계속 편집).

### 새 파일

**New** → 빈 문서로 시작합니다. 역시 저장 안 한 변경이 있으면 먼저 물어봅니다.

### 저장하기

**Save** → 파일 이름과 확장자를 정하는 시트가 뜹니다 → **Continue to Files**.

- iOS 공유 시트가 열리면 **파일에 저장(Save to Files)** 을 골라 원하는 위치(iCloud Drive 등)에 넣습니다.
- 파일 이름에는 **한글을 그대로 쓸 수 있습니다.**
- `/ \ : * ? " < > |` 는 파일 이름에 쓸 수 없어 미리 막습니다.

> **Quill은 원본 파일에 덮어쓰지 못합니다.**
> iOS Safari에는 웹앱이 파일을 제자리에 저장하는 기능이 없습니다. 항상 **새 사본을 Files로 내보내는** 방식입니다. 같은 이름으로 같은 위치에 저장하면 Files가 덮어쓸지 물어봅니다.

### 검색

**Find** → 검색어를 입력합니다.

- **Next / Prev**: 다음·이전 일치로 이동합니다. 끝에 닿으면 처음으로 돌아옵니다.
- **Match Case**: 대소문자를 구분합니다.
- **Close**: 검색을 닫습니다.
- 일치가 없으면 `No matches`, 있으면 `2 / 7`처럼 위치가 표시됩니다.
- 검색어는 정규식이 아니라 글자 그대로 찾습니다. `.` 나 `*` 도 그냥 그 문자로 찾습니다.

### 키보드가 있을 때 (iPad + 외장 키보드)

| 키 | 동작 |
|---|---|
| `Tab` | 들여쓰기 (선택 영역이 있으면 줄 전체) |
| `Shift + Tab` | 내어쓰기 |
| `Enter` | 줄바꿈 + 앞 줄의 들여쓰기 이어받기 |
| `⌘ + F` | 검색 열기 |
| `⌘ + S` | 저장 |
| `Esc` | 검색 닫기 |

한글을 입력하는 도중(조합 중)에는 이 단축키들이 끼어들지 않습니다.

## 3. 자동 저장과 복구

타이핑을 멈추면 잠시 뒤 이 기기에 초안이 저장되고, 화면 아래에 `Draft saved on this device` 가 표시됩니다.

앱을 껐다 켜면 그 초안이 자동으로 돌아오고 `Draft restored` 가 표시됩니다.

> **초안은 이 기기에만, 한 건만 저장됩니다.**
> 여러 문서를 동시에 보관하지 않습니다. 다른 파일을 열면 이전 초안은 대체됩니다. **계속 보관할 내용은 반드시 Save로 Files에 내보내세요.**

---

## 3-1. 스냅샷(Snapshot) — 되돌리기

큰 수정을 하기 전에 지금 상태를 남겨 두고 싶을 때 씁니다. **자동으로 저장되지 않고, 눌렀을 때만** 저장됩니다.

1. 상단 도구모음의 **Snapshots**를 누릅니다.
2. **Save a snapshot now**를 누르면 지금 화면의 전체 본문·시각·글자 수·파일 이름이 저장됩니다.
3. 목록에서 항목을 누르면 **읽기 전용 미리보기**가 열립니다.
4. 미리보기에서 **Restore(복원)**를 누르면 지금 편집 중이던 내용이 그 시점으로 되돌아갑니다.

> **복원하기 직전, 지금 화면의 내용도 스냅샷 하나로 자동 저장됩니다.** 복원을 취소하고 싶으면 방금 만들어진 그 스냅샷을 다시 복원하면 됩니다.
> 복원과 삭제는 실행 전에 확인을 받습니다.

**파일 하나당 최대 10개**까지 보관됩니다. 11번째를 저장하면 가장 오래된 것부터 자동으로 지워집니다.

스냅샷은 **이 앱의 저장 공간(IndexedDB)에만** 있습니다. 원본 파일은 iOS 제약으로 Quill이 직접 덮어쓸 수 없으므로, 스냅샷을 "그 파일"로 되돌리려면 복원한 뒤 Save로 새 사본을 Files에 내보내야 합니다.

Settings → Data의 **"Include snapshots(스냅샷) in backup"**을 켜 두면(기본값) JSON 백업에 스냅샷도 함께 담겨 다른 기기에서 복원할 수 있습니다. 끄면 백업 파일이 작아지지만 스냅샷은 백업에 들어가지 않습니다.

## 4. 설정(Settings)

### Interface Size — 화면 글자 크기

메뉴·버튼·설명의 크기입니다. 6 / 8 / 10 / 12 / 14 / 17 여섯 단계이고 기본은 12입니다. **Reset** 으로 기본값으로 돌아갑니다.

글자를 작게 해도 버튼의 터치 영역은 그대로 유지됩니다.

### Text Size — 본문 글자 크기

편집 중인 문서의 크기입니다. 16 / 18 / 20 / 24 / 28 / 32 이고 기본은 16입니다.

16보다 작은 값이 없는 이유는, iPhone Safari가 16px보다 작은 입력창을 탭하면 화면을 자동으로 확대해 버리기 때문입니다. 한 화면에 많이 보고 싶으시면 **Interface Size** 쪽을 줄이세요.

### Editing — 편집

- **Tab spaces**: `Tab` 키가 넣는 공백 칸 수 (2 / 4 / 8)
- **Word wrap**: 긴 줄을 화면 폭에서 접습니다. 끄면 좌우로 스크롤합니다. 코드나 표를 볼 때는 끄는 쪽이 편합니다.
- **Spellcheck**: 맞춤법 밑줄
- **Autocorrect**: 자동 수정·자동 대문자. 코드를 쓸 때는 꺼 두는 쪽이 좋습니다.

### Extension — 확장자

새 파일을 저장할 때 기본으로 붙는 확장자입니다. 목록에서 고르거나 **Custom** 에 직접 입력합니다 (`.txt`, `.md` 같은 형태).

### Data — 데이터

- **Export Backup**: 초안과 설정을 JSON 한 개로 내보냅니다. 파일 이름은 `quill-backup-2026-08-06.json` 형태입니다.
- **Restore Backup**: 그 JSON을 다시 가져옵니다. 형식을 먼저 검사하고, 덮어쓰기 전에 물어봅니다.
- **Clear recovery data**: 저장된 초안만 지웁니다.
- **Clear Data**: 초안·설정·화면의 글을 모두 초기화합니다.

> **백업에는 문서가 들어 있지 않습니다.** 초안 1건과 설정뿐입니다. 실제 파일은 Files 앱에 있으므로, 문서 보관은 Files(iCloud Drive)에서 하시면 됩니다.

## 5. 새 버전과 캐시

새 버전이 배포되면 앱을 열었을 때 `Update available` 안내가 잠깐 뜹니다. **앱을 완전히 종료했다가 다시 열면** 새 버전이 적용됩니다.

계속 이전 화면이 보이면:

1. 홈 화면 앱을 완전히 종료합니다 (앱 전환기에서 위로 밀어 올리기)
2. 다시 엽니다
3. 그래도 그대로면 Safari에서 같은 주소를 한 번 열어 봅니다

## 6. 문제가 생겼을 때

| 증상 | 확인할 것 |
|---|---|
| 초안이 안 돌아옴 | Safari 탭과 홈 화면 앱을 섞어 쓰지 않았는지. 두 곳은 저장 공간이 분리됩니다. |
| `Draft save failed` | 기기 저장 공간이 부족하거나 비공개 브라우징 상태일 수 있습니다. 중요한 내용은 바로 **Save** 로 내보내세요. |
| 저장이 안 됨 | 공유 시트에서 취소하지 않았는지 확인하고 다시 **Save** 를 누릅니다. |
| 파일 이름 오류 | `/ \ : * ? " < > |` 가 들어갔는지 확인합니다. |
| 화면이 확대됨 | Text Size가 16 이상인지 확인합니다. |
| 오프라인에서 안 열림 | 온라인 상태에서 한 번 열어 두어야 오프라인 캐시가 만들어집니다. |

## 7. 개인정보

- Quill은 **동기화를 켜지 않는 한 어떤 데이터도 외부로 보내지 않습니다.** 로그인, 분석 도구, 광고가 없습니다.
- 동기화를 켜도 나가는 것은 **설정값 7개뿐**입니다. 글과 초안은 켜든 끄든 이 기기에만 있습니다.
- 초안과 설정은 이 기기의 브라우저 저장 공간에만 있습니다.
- Safari의 웹사이트 데이터를 지우면 초안과 설정도 함께 지워집니다. 중요한 글은 Files에 내보내 두세요.


## 6. 동기화 (Sync)

`Settings`의 `Sync`에서 켭니다. **처음에는 꺼져 있고, 꺼진 상태에서도 Quill은 전부 그대로 동작합니다.**

> **올라가는 것은 설정 7개뿐입니다.** UI 글자 크기, 에디터 글자 크기, 들여쓰기 칸 수, 줄바꿈, 맞춤법 검사, 자동 수정, 기본 확장자.
> **쓰던 글과 자동 저장된 초안은 절대 올라가지 않습니다.** 초안은 한 기기에서 쓰는 중인 글이라, 기기 간에 섞이면 덮어쓰기 사고가 나기 쉽기 때문입니다.

켜는 순서는 이렇습니다.

1. **Device name**을 먼저 적습니다. **영문 소문자와 숫자만** 씁니다 (예: `iphone-home`).
2. **Access token**을 붙여 넣고 `Save token`을 누릅니다.
3. `Turn sync on`을 누릅니다.

> **기기 이름은 켜기 전에 적어야 합니다.** 이름은 켜는 순간 파일 이름으로 굳고 나중에 바꿀 수 없습니다.
>
> 같은 iPhone이라도 **Safari 탭과 홈 화면에 추가(Add to Home Screen)한 앱은 서로 다른 기기로 셉니다.**

### 어떻게 동작하는가

- **설정을 실제로 바꿨을 때만 올라갑니다.** 앱을 켜기만 해서는 아무것도 올라가지 않습니다. 새로 깐 기기의 기본값이 다른 기기에서 맞춰 둔 설정을 덮지 않게 하기 위해서입니다.
- 앱을 열 때 다른 기기의 설정이 **더 최근에 바뀐 것이면** 그것을 받아 적용하고 `Settings updated from another device.`라고 알려 줍니다.
- 같은 시각이거나 내 쪽이 더 최신이면 화면이 그대로 유지됩니다.
- `Sync now`로 직접 돌릴 수도 있습니다.
- `Settings` → `About`의 **App version**이 지금 이 기기에서 실제로 돌고 있는 버전입니다.

## Daybook Journal과 활동 백업

- 이 버전부터 created/opened/edited/export-requested 메타데이터를 Journal ON/OFF와 무관하게 90일 보관합니다. 이전 과거는 추정하지 않아 `future-only`입니다.
- **Add captured history**는 이 실제 원장 범위만 가져옵니다. 본문과 내용 hash는 Journal에 포함되지 않습니다.
- 원장은 일반 JSON backup의 optional 필드로 내보내고 구버전 backup도 계속 복원합니다. **Clear captured activity**는 draft와 remote Journal record를 건드리지 않습니다.
